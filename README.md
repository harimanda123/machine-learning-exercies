# Machine Learning Exercises

A collection of machine learning notebooks covering neural network architectures using Keras and PyTorch.

## Notebooks

### 1. Recurrent Neural Networks – GRU (Keras)
**File:** `RecurrelNeuralNetworks_GRU_Keras.ipynb`

Implements a Gated Recurrent Unit (GRU) network using Keras. GRUs are a type of recurrent neural network (RNN) designed to handle sequential data and long-range dependencies, making them well-suited for time series, text, and other sequence modelling tasks.

---

### 2. Fully Connected Neural Network – Regression (PyTorch)
**File:** `FullyConnectedNeuralNetwork_Regression_PyTorch.ipynb`

Builds a fully connected (dense) neural network using PyTorch for regression tasks. Covers dataset preparation, model definition, training loop, loss tracking, and evaluation on continuous output prediction.

---

### 3. Fully Connected Neural Network – Classification (Keras)
**File:** `FullyConnectedNeuralNetwork_Classification_Keras.ipynb`

Builds a fully connected neural network using Keras for classification tasks. Covers data preprocessing, model architecture, compilation with categorical cross-entropy loss, training, and accuracy evaluation.

---
